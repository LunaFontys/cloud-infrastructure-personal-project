# Project Start



### Date

7 September 2026



### Project

Cloud Application \& Infrastructure



### Starting Point



Before starting this project, most of my experience has been in software development,

particularly projects involving applications and XR. I have less practical experience

working directly with infrastructure.



I have previously experimented with cloud platforms and basic deployment, but I have

not yet built and operated a complete infrastructure workflow involving containerisation,

CI/CD, networking, security, monitoring, and infrastructure automation.



I have very little practical knowledge of containerisation.

I understand the general purpose of CI/CD, but I do not yet understand how CI/CD

pipelines are designed or implemented.



### Why I Chose This Project



I want to get a good understanding of Cloud Engineering and Infrastructure as a whole,

because I am interested in eventually working in this field. I think this project is a good

and challenging starting point for someone with very little infrastructure experience.



I want this project to focus mainly on Infrastructure. The application itself will therefore

stay relatively simple so that most of the learning can focus on the infrastructure surrounding it.



### What I Want to Learn



During this project I currently want to learn more about:



\- Linux servers and virtual machines

\- Docker and containers

\- CI/CD

\- Cloud deployment

\- Networking and reverse proxies

\- Infrastructure security

\- Logging and monitoring

\- Infrastructure automation



I do not expect to use every technology listed above automatically. Choices will be made

based on research, experiments, and the needs of the project.



### Current Competence Direction



This project is primarily intended to develop and explore Infrastructure while also

producing some Software evidence.



I am currently moving my focus away from XR and more toward Infrastructure. Because I

have less prior experience in this area, I know I will need to build a substantial amount

of new knowledge and evidence during this semester.



Depending on the work and evidence produced in the group challenges, I also want to keep

Software at level 2 as a realistic part of my competence profile.



### Current Expectations



I expect that infrastructure work will involve more configuration, troubleshooting,

automation, networking, and system-level reasoning than my previous XR projects.



One of the goals of this project is to discover which parts of this work I enjoy, which parts

I find difficult, and how much I can develop my Infrastructure competences during the semester.
