# ADR-001: Hosting Platform



### Date

7 September 2026



## Problem



I need a hosting environment where I can deploy and operate the application while

learning infrastructure concepts such as virtual machines, networking, security,

deployment, monitoring, and automation.



## Options Considered



\- AWS

\- EduCloud

\- Azure

\- Local machine



## Criteria



\- Cost

\- Infrastructure control

\- Learning value

\- Availability

\- Automation possibilities



## Decision



EduCloud will be used as the primary hosting platform.



## Reason



EduCloud is available through Fontys without financial risk and gives direct access

to infrastructure such as virtual machines, networking, and storage.



This makes it suitable for learning infrastructure concepts directly instead of

starting with a heavily managed hosting platform.



## Consequences



\- I will need to manage more of the server and infrastructure myself.

\- There is no cloud billing risk for the main project environment.

\- I will gain less direct experience with a public cloud provider such as Azure.

\- Azure can still be compared or explored later if it adds useful learning value.
